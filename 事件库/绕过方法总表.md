# 绕过方法总表（本项目全部手段 · 适用条件 · 红线 · 做不到的）

> 2026-09-24。用户要求：「**一切的绕过东西方法手段 都总结放进绕过功能里面**」。
> 本文是**唯一入口**：以后问"这能不能绕"，先查这里；新增手段也登记在这里。

## 一、先分层：能不能绕，取决于**在哪一层**
| 层 | 能做什么 | 关键前提 |
|---|---|---|
| **① 客户端权威层** | 直接改位置/速度/CFrame/属性 | **该服没有 Server Authority**（有 SA ⇒ 引擎直接拒绝） |
| **② 上行通道层** | hook `FireServer` 改写"上报值" | 该服**存在位置上行通道**；且**只对单帧大跳有意义** |
| **③ 本地表现层** | 透视/高亮/自绘/翻译 | **永远有效**（不依赖服务端） |
| **④ 检测面层** | 隐身/反指纹/中性名 | 不改变服务端判定，**只降低被抓概率** |

★ **判断顺序**：先测 ①（`AuthorityMode`），再找 ②（有没有上行通道），再看 ③/④。
**别在不可能的层上耗时。**

## 二、手段总表（按现有模块）
| 目的 | 手段 | 模块 / 开关 | 适用条件 | 做不到的 |
|---|---|---|---|---|
| 飞行 / 加速 | 本地约束或直接写 | `SYS._Move` + `C_.FlyAbs` / `C_.SpeedAbs` | 仅**客户端权威**服 | SA 服全废（引擎拒绝） |
| **防回退（过检测）** | 改写/限速上行位置 | `T_.AntiRevert` + `C_.RevertCap` / `C_.RevertJump` | 存在位置上行通道 | 无通道/SA 服无效；**不能伪装持续高速**（见 §四） |
| 反作弊通道拦截 | 拦"发往 AC/审计通道"的上行 | `T_.ACBlock` | 名字像 AC/审计 | 服务端判定不变 |
| 上帝 / 锁血 / 补血 | 本地免疫 + 属性写回 | `SYS.SetGod` · `DeadRails_LockHp` · `T_.AttrGuard` | **伤害在客户端结算**的服 | **服务端算伤害 ⇒ 真无敌做不到** |
| 属性回写（防判死） | 写 Player Attribute | `T_.AttrGuard` | 属性为客户端可读写 | 服务端会覆盖 |
| 隐身 | `debug.info` 伪装（**5 层**） | `T_.Prot_Stealth` | 执行器有 `checkcaller` | 逐帧遍历 GUI / 比较函数身份 |
| 反指纹 | 中性名 + `Archivable=false` + 文字脱敏 | `SYS.Prot` · `T_.Prot_UImask` | — | **菜单开着的那一瞬间拦不住** |
| 静默瞄准 / 子弹穿墙 | 射线改写（函数层 hook） | `RayHook`（可选 `Prot_RayNamecall`） | 存在可命名的射线函数 | 总入口 hook 已被禁/有风险 |
| 传送 | 分步链（多帧小步） | `SYS.TPTo` / `tpStepChain`（+ `RevertJump`） | 客户端权威 | SA 服无解 |
| 上行伪装 | 开火抖动 / 参数类型签名 | `C_.FireJitter` · `C_.FireTypeSigN` | — | 只降低"机器节奏"特征 |
| 会话指纹 | 名字池随机 / 创建错峰 / 数值微抖 | L 段（`SYS.Stagger` 等） | — | 只降低"每次都一样"特征 |
| 位置下行回压 | 服务端推来的位置下一帧盖回 | `T_.PosRebound` | 有下行位置通道 | 和游戏抢位置，可能抖/被更强校验发现 |
| 交互物透视 | `ProximityPrompt` / `ClickDetector` 高亮 | 「🔍 物件透视」（`SYS.FindGrabbables`） | 交互物在客户端可见 | 服务端 StreamingEnabled 剔除的看不到 |

## 三、⛔ 红线（**永远不做**）
`hookmetamethod(game,"__namecall"/"__index")` 关键词搜索 · 任何**服务端伪造** ·
`getrawmetatable` / `setreadonly` · 给游戏内部表灌元表 · 整脚本仿真。

## 四、★ 必须记住的物理事实（两条）
1. **「跑得快」与「看起来正常」不可兼得** —— 上报速度上限低于实际速度 ⇒ 服务端拽回；
   高于 ⇒ 等于没做。所以 `AntiRevert` 默认开只做"**TP 不显眼**"。
2. **服务端结算的东西客户端拦不到** —— 真无敌 / 锁血（血条回弹）/ 服务端位置校验拉回 / 真踢封。

## 五、新服上手标准流程（照着走，别瞎试）
1. 「**总扫描**」→ 看 **功能可用性总表**：若 **≥80% ❌** ⇒ **框架式命名**（remote 全是框架动词，别名搜索天生无效，脚本会直接告诉你）。
2. 「总扫描」→ **移动环境层**：`Workspace.AuthorityMode = Server` ⇒ **移动类当场结案**。
3. 判断该走哪层：客户端权威？有上行通道？有交互物（Prompt/ClickDetector）？
4. **只做那一层能做的**，其余如实告知"做不到"。
