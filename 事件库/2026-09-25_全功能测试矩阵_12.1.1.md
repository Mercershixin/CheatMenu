## 四、验不了的部分 + 真机 30 秒快验清单

### ⛔ 必须真机（本机无 Roblox）
1. 一切**依赖引擎**的行为：物理位移、高亮绘制、射线改写、GUI 布局。
2. 一切**依赖具体游戏**的行为：Dead Rails 锁血/防击倒、各服的 remote 命中。
3. **卸载是否干净**：关菜单后功能是否真停、连接是否真断（静态只能证明"有还原代码"）。

### ✅ 真机快验流程（按顺序，5 步）

1. **加载** → 看控制台有没有 `❌` / `⚠ 错误显形[...]`。
   ★ V3 起的规矩：**任何任务第一次出错都会显形**，不再静默——这一行就是排查入口。
2. 打开菜单 → 进「事件」页 → 点 **🔁 立即重建图谱** → 应弹出「🧩 图谱: N 条」。
3. 进「功能」页（或任意页）→ 点 **🔍 综合扫描** → 控制台应出 **19 段**，
   且**第 1 段就是「🛡 能力绕过判定」**（飞行加速/回血/锁血/上帝/高亮/透视/传送 逐条判定 + 三条硬前提）。
4. 逐页拨几个开关（飞行、加速、物件透视、上帝）→ **每一项都要"看得见效果"**；
   没效果 → 回「事件」页点 **🩺 查看运行态**，看 `任务数/驱动连接/错误数`。
   - 任务数不涨 ⇒ 开关没接线
   - 错误数在涨 ⇒ 直接看「📜 导出错误清单」
5. 关掉菜单（或卸载）→ 确认功能**真停**；再开一次 → 确认开关状态**被还原**。

### 已知的"正常但看着像坏"（别误判）
| 现象 | 真相 |
|---|---|
| 透视在远处看不到人/物 | `StreamingEnabled = true`：服务端没下发的实例客户端根本没有（走近才出）——**引擎行为** |
| 飞不动 / 人被拽回 | `AuthorityMode = Server`，或上报上限低于实际速度 —— **物理限制**，见扫描第 1 段 |
| 血条回弹 | 伤害在服务端结算 —— **真无敌做不到** |
| 扫描某段是 0 | 该游戏确实没有那类东西（例如没有治疗 remote） |
