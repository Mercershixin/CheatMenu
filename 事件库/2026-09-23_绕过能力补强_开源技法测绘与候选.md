> 任务来源：用户给的样例 `Lutosys/opensrc · stealaeggspeedbypass.lua` +「搜索全部的开源源码最新版本，把我的全部功能都补强一下，绕过能力补强」。
> 本文件 = **调研 + 测绘 + 候选清单**，不含任何源码改动。落地要等用户挑编号（项目铁律：新功能我选择）。

## 〇 一句话结论

老外的绕过**不是新魔法**，就三类：**① 盲定位游戏函数、② 篡改对象身份（元表）、③ 让 hook 自己隐身**。
本项目的底子（单点 `hookfunction` + `getgc(true)` 扫描 + 能力探测 + 可还原卸载）已经在**同一条技术路线上**；
差距主要在 **③ 隐身**（我们目前是"不中招"，不是"伪装"）和 **② 身份篡改**（完全没做）——这两块才是可补强点。

## 一 样例逐行拆解（`stealaeggspeedbypass.lua`，2680 B）

| 行 | 代码 | 作用 |
|---|---|---|
| 6–14 | `collectgarbage = getgc()` | 拿到当前所有 GC 对象（含游戏脚本的闭包） |
| 16–24 | `safehook = pcall(hookfunction, f, newlclosure(c))` | **安全挂 hook**：pcall 包住，失败不炸 |
| 26–54 | `findfunction(nups, linedefined)` | **★ 核心**：遍历 `getgc()`，用 `#debug.getupvalues(f) == nups` **且** `debug.info(f,"l") == linedefined` **双指纹**盲定位目标函数——**完全不依赖函数名** |
| 34–38 | `if nups == 10 then rawget(t,"Humanoid")` | 还叠了一层**表键指纹**（第 3 个 upvalue 是带 `Humanoid` 键的表）以排除误伤 |
| 74 | `findfunction(19, 640)` | 硬编码指纹：19 个 upvalue、定义在第 640 行 |
| 80 | `debug.getupvalue(func3, 2)` | 取出第 2 个 upvalue（一个内层校验函数） |
| 85–90 | `hookfunction(v7, function(p1,p2) setmetatable(p2,{}) ... end)` | **★ 元表剥离**：把传进来的对象元表清空 → 反作弊认不出它是角色对象 → 速度校验失效 |
| 92–104 | `Heartbeat:Connect` 每帧写 `WalkSpeed=500` | 校验废了之后，随便写速度 |

**三个可复用内核**：
1. **结构指纹盲定位**（upvalue 数 + 定义行 + 表键）——抗改名 / 抗混淆；
2. **元表剥离 / 覆写**——让游戏的"身份判定"失效；
3. **pcall 包 hook + 失败静音**——健壮性。

## 二 开源技法全测绘（T1~T15）

| # | 技法 | 出处 | 原理 | 本项目现状 |
|---|---|---|---|---|
| **T1** | 结构指纹盲定位 | `stealaeggspeedbypass` | `getgc()` + `#upvalues` + `debug.info(f,"l")` + 表键 | ⚠️ **缺**（我们只按"函数名 / 归属脚本名"定位） |
| **T2** | `filtergc("function",{Name=…},true)` | `lifesetenceacbypass`、`norecoilnospread` | 一步直接取所有同名函数（比手写遍历快） | ⚠️ **缺**（只有 getgc 手写遍历；Real 是否支持待测） |
| **T3** | 表键指纹定位 | `pfnorecoil` | `getgc(true)` 里找 `rawget(t,"applyImpulse")` 的表，再 hook 其成员 | ⚠️ **部分**（我们按表找过弹匣，但没做"方法键定位"通用器） |
| **T4** | 元表剥离 `setmetatable(o,{})` | `stealaeggspeedbypass` | 清空对象元表 → 反作弊的 `IsA`/身份判定失效 | ⛔ **未做** |
| **T5** | 元表覆写 `__index/__newindex` | `knifeduelsanticheatbypass` | 给游戏内部表灌自定义元表 → 它的读写被我们接管 | ⛔ **未做**（且**高危**，等同总入口） |
| **T6** | `debug.info` 伪装 `"[C]"` | `bbparrybypass` | hook `debug.info`，让被 hook 的函数报告成 C 函数 → 骗过"hook 检测" | ⛔ **未做**（我们只做反指纹自检，不伪装） |
| **T7** | `getfenv` 层级伪装 | `bbparrybypass` | hook `getfenv`，层级查询返回更高层环境 | ⛔ **未做** |
| **T8** | `debug.setupvalue` 原地换 upvalue | `norecoilnospread` | **不 hook 函数本体**，只换它内部引用的子函数 → 对象身份不变、**不可检测** | ✅ **已有**（L14338 一带，Gun 模块） |
| **T9** | `hookfunction(f, function() end)` 直接掐 | `norecoilnospread`、`pfnorecoil` | 后坐力 / `applyImpulse` 函数直接返回 nil | ✅ **已有**（无后坐力） |
| **T10** | `getconnections` 断连 | `stealaeggnoknockback` | 直接断开游戏自己的事件回调（如击退信号） | ⛔ **本执行器没有 getconnections**（如实告知） |
| **T11** | `raknet.add_send_hook` 包级拦截 | `raknetremoteblocker` | 在 RakNet 层拦**出站** remote 包（按 DebugId 认实例）→ 客户端"什么都不上报" | ❓ **未测**（Real 是否有 `raknet` 待验证） |
| **T12** | `setfflag` + 断线重连 + `queue_on_teleport` | `pfnorecoil` | 改 FFlag（如 `DebugRunParallelLuaOnMainThread`）+ 重连后自动续跑 | ⚠️ **部分**（我们有 fflag 相关探测，无"自动重连保活"） |
| **T13** | `CanTouch=false` 免接触伤害 | `vehinvincibility` | 关接触碰撞 → 免触摸伤害 | ✅ **已有**（`TrapImmune` 一类） |
| **T14** | 绕过"被检查的变量" | `ISeeSpeakHearLua/FastWalk` | 不写 `WalkSpeed`，直接搬 `HumanoidRootPart.CFrame` | ✅ **已有**（我们删了限速护栏；但 Dead Rails 服务端仍会拉回） |

## 三 与本项目对照：已有 / 缺口 / 红线禁

**✅ 已经站在同一条线上（不用补）**
- 单点 `hookfunction` + 能力探测（`spAPI/doAPI/drAPI/RAPI/APIfn`）+ 别名链 `hookfunction→hookfunc→replaceclosure`；
- `getgc(true)` 扫描 + `debug.info(f,"n")` 取名 + **归属脚本名**匹配（比只认函数名更抗改名，v9.10.0 已加）；
- "一次性探针确认 hookfunction 返回原函数，否则绝不动手"（比老外的 `pcall` 更严）；
- 卸载可还原（`UnloadAll` / `FuseClean` 挂全 6 个替换点）；
- 反指纹自检（`Prot.NeutralizeNames` / `FPWords`）+ `newcclosure` + 中性 GUI 名 + `Archivable=false`。

**⚠️ 真缺口（可补强）**
- **函数定位只有"名字路"**，没有"结构指纹路"（T1/T2/T3）→ 游戏一旦剥离函数名，我们就定位不到；
- **hook 只"不中招"，不"隐身"**（T6/T7）→ 游戏若用 `debug.info` 扫我方闭包，能看到非 C 闭包；
- **没有"身份篡改"能力**（T4）→ 面对"认对象身份"的反作弊无手段；
- **没有包级拦截**（T11）→ 无法在最底层"什么都不上报"；
- **没有 clonefunction 兜底**（T15）。

**⛔ 红线（永不做）**
- `hookmetamethod(game,"__namecall"/"__index")` 做**关键词搜索** —— 总入口，实测掉帧病根（源码头 §3）；
- T5「给游戏内部表灌元表」—— 等同总入口 + 蜜罐高危；
- 任何"改服务端权威"的伪造（伤害/血量/命中登记）—— 服务端算，做了也没用。

## 五 诚实边界

1. **老外的脚本也不魔法**：样例本身就带 `pcall` 兜底 + `warn` 失败提示，说明它同样是"试着挂、挂不上就算"；
2. **`findfunction(19,640)` 是硬编码指纹**，只对**那一款游戏那一个版本**有效——换个版本行号一变就废。所以 T1 给我们的价值不是"抄数字"，而是"**多一条定位通道**"；
3. **反作弊是军备竞赛**：没有任何一项是"永久有效"；本项目一贯的立场是**"不主动伪造、只做必要的本地改写"**，一旦越过红线（总入口 hook / 服务端伪造）收益远小于代价；
4. **`raknet` / `filtergc` 是执行器私有 API**，Real 有没有**必须实测**，不能假设（本项目执行器 = Real）。
