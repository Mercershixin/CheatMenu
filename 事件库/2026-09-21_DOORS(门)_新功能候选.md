## 〇、一句话结论

**这局里能做的全是「只读」类**（监听收向信号 / Invoke 查询），
**凡是"主动 FireServer 让服务器给你东西"的，DOORS 基本都做不到** —— 图鉴/成就/复活/存档都是服务端权威，
客户端发过去不会真生效，而且这一发会被记下来。

### 实现备注（要加的话需要补的支撑）

- 第 1/2/3/10 条都是 **UnreliableRemoteEvent**。现有 `SYS.OnRemote(name,cb)` 走的是
  `SYS.REvent()`（只找 `RemoteEvent`），**收不到 Unreliable** ——
  需要补一个 `SYS.OnRemoteU(name,cb)`（用现成的 `SYS.REventU()` 取到对象再 `OnClientEvent:Connect`）。
- Unreliable 是**高频**通道：回调里必须做时间聚合（如 0.2s）再更新 UI，别每条都重画。

## 二、⚠ 中风险（要做也只做"手动点一次"，别做成自动）

| # | 功能 | 信号 | 为什么中风险 |
|---|---|---|---|
| 12 | **一键解卡（Unstick）** | `…RemotesFolder.Unstick` | 是"请求解卡"，**给不给由服务端决定**；做成自动会不停刷请求，请求频率本身就是异常特征 |
| 13 | **礼物复活 / 赠送复活** | `…ObtainGiftedRevive`、`…GiftProduct`（对应 leaderstats `Gifts`） | 会真的动账（消耗礼物），且服务端校验。**只适合手动点一次**，别自动 |
| 14 | **图鉴（Journal）系列** | `JournalUnlock` / `JournalDiscover` / `JournalRead` / `JournalRefresh` / `JournalSkinChanged` | **服务端权威**：客户端发过去不会真解锁，最多本地 UI 演一下；而且这几次发信会被记录。⚠ 别做 |
| 15 | **存档相关** | `…SaveHandler`、`…ContinueOrSave` | 碰存档＝碰进度数据，风险高于收益 |

## 三、⛔ 明确不要碰

| 信号 | 为什么 |

| `ReplicatedStorage.RemotesFolder.DroneStickyNoteMyNameIsExploiterAndIThinkICanCheatWithThis` | **蜜罐**。名字直接写着"我是开挂的、我以为用这个能作弊"。谁 `FireServer` 谁被记录 |
| `ReplicatedStorage.conch_networking.*`（`register_command` / `log_command` / `invoke_server_command` / `create_user` / `update_user_roles` / `log` / `ready`） | 后台命令 + 审计通道。触发＝自报家门 |
| `ReplicatedStorage.RemotesFolder.AdminPanelRunCommand` | 管理后台执行入口 |

| `…PurchaseShopItem` | 付费服务端权威。**白嫖付费物品做不到**（AGENTS 里已写明），发过去只是留痕 |

## 四、附：现有 36 个功能类别在 DOORS 的命中情况

**命中 11 个**（说明这些现有功能在 DOORS 里本来就能用）：

`chat` `deathfx` `doors` `doorshop` `equip` `inventory` `itemuse` `pickup` `respawn` `revive` `teleport`

**未命中 25 个** —— 这是**正常的，不是 bug**，本游戏没有同名通道：

`heal` `kill` `damage` `buy` `claim` `sell` `trade` `round` `kick` `unequip` `orb` `daily`
`craft` `stall` `loot` `shop` `box` `mail` `friend` `milestone` `server` `team` `emote` `combat` `move`

> 其中 `heal` / `kill` / `damage` 这类在 DOORS 本来就不该有（这游戏没有"治疗/击杀"的玩家侧通道）；
> `buy` / `shop` / `claim` / `daily` 这类是通用型，DOORS 用的是自己的 `RequestShop` / `PurchaseShopItem`，
> **想接上就把这两个名字加进 `SYS.RemoteAlias` 对应类别里**（`shop` 加 `RequestShop`，`buy` 加 `PurchaseShopItem`）——
> 但 `PurchaseShopItem` 是付费，建议**只加 `shop` 的查询项**。
