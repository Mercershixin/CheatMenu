### 2.1 三条可直接复用的实现（一手源码原文要点）

**① `bbparrybypass.lua`（24 行 · 隐身）**
```lua
local old
old = hookfunction(getrenv().debug.info, function(f, t)
    if type(f) == "function" then return "[C]"                  -- 任何函数都报成 C 函数
    elseif f == 4 and t == "s" then return "ReplicatedStorage.Controllers.SwordsController " end
    return old(f, t)
end)
local old2
old2 = hookfunction(getrenv().getfenv, function(l)               -- 栈层隐藏: 1~10 一律给第 10 层
    if l ~= nil and type(l) == "number" and l >= 1 and l <= 10 then return old2(10) end
    return old2(l)
end)
```
→ **要点：hook 的是 `getrenv()` 里的副本，不是全局那份。** 本仓原 stealth 只遮全局 `debug.info` ⇒ 已按此**补强成 3 层**。

**② `lifesetenceacbypass.lua`（5 行 · 定向阉割）**
```lua
local GetPlayerBanned = filtergc("function", {Name = "GetPlayerBanned"}, true)
hookfunction(GetPlayerBanned, function() warn("tried to ban you") end)
```
→ `filtergc` 按 **Name** 直取游戏函数、hook 成 no-op。本仓已吸收"按名字直取"为 `SYS.FindFn`；
"定向阉割 ban/kick 函数"作为**候选**（需先确认目标名，见 §四 B-3）。

**③ `raknetremoteblocker.lua`（· 包级拦截）**
```lua
raknet.add_send_hook(function(packet)
    if packet.PacketId == 0x83 then                       -- 0x83 = RemoteEvent/Function 发送
        local b = packet.AsBuffer
        ... local inst = data[buffer.readu32(b, i)]
        if table.find(blocked, tostring(inst)) then return packet:Block() end
    end
end)
```
→ 出向包级拦截。作为**候选 B5**（需 Real 有 `raknet`）。

**④ `knifeduelsanticheatbypass.lua`（18 行 · 元表盲灌）** ⛔ **不采纳**
```lua
for _, func in next, getgc() do
    if typeof(func)=="function" and debug.getinfo(func,"n").name=="f" then
        for _, upvalue in pairs(debug.getupvalues(func)) do
            if typeof(upvalue)=="table" then setmetatable(upvalue, {__index=…, __newindex=…}) end
        end
    end
end
```
→ 给"名叫 f 的函数的所有 table upvalue"盲灌元表 —— **违反本仓红线（不给游戏内部表灌元表）**，且极易搞坏游戏。
**只记其"结构指纹定位思路"（`debug.getinfo(f,"n").name` + `debug.getupvalues`），不抄行为。**

**⑤ `FightinAschoolfullsource.lua`（getcallingscript 洁净值 + 自带 SafeHook）**
```lua
self.metahook = self:SafeHook("hookmetamethod", "__index", function(s, key)
    if tostring(s) == "Class" and key == "Value" then
        if tostring(getcallingscript()) == "Core" or tostring(getcallingscript()) == "Interface" then
            return StyleClassesList.Value        -- 游戏自己读 -> 给"干净"的真值
        end
        return self.targetstyle                  -- 别的调用者 -> 给改过的值
    end
end)
```
→ **`getcallingscript()` 分流**：游戏自身脚本读 = 给原本的正确值（骗过校验），其它 = 给我们的值。
本仓已有 `getcallingscript`（反查层/环境层）；此手法作为**候选 B-4**（需要落到具体被读字段）。
> ⚠ 注意：它是 `hookmetamethod(...,"__index")` —— **本仓红线**，若采纳此思路须改成"单点 hookfunction 具体函数"的等价形态。
