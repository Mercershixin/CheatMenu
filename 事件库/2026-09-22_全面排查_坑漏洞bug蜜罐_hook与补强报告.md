## ② 三个真 bug / 缺陷（**都不是编译能发现的**）

### ②-1 ⛔ `TryAntiKick`：自动 hook `Player:Kick`，无开关、无还原

```lua
function SYS.TryAntiKick()          -- 菜单挂载时【无条件】被调用
    hookfunction(lp.Kick, function() return nil end)   -- 挂上就再也卸不掉
end
```

它正是 **v9.9.8 判定"防不住、且 hook 本身就是可检测指纹"要删的那一类**，
当时删掉了 `InstallKickGuard` 与界面开关，**但这个不同名的实现活了下来**。

三重问题：① 真实踢人由**服务端**发起，客户端 hook 拦不到；② 替换函数**可被反查**
（反作弊对非玩家对象调 `Kick`，看是否返回 `nil` 就能认出你替换过）；③ **无还原**且**无条件自动挂**。

⇒ **已彻底删除**（函数体 + 调用点 + 文件头/A33 注释同步，共 4 处）。

### ②-2 ⛔ 卸载不等于还原：`UnloadAll` 漏了两个 hook/改写层

| 漏掉的 | 后果 |
|---|---|
| `SYS.Gun.Sync()` | 开着「无后坐力」时 hook 的是**游戏自己的后坐力函数**，替换体是 `function() return nil end` ⇒ 卸载后**游戏的后坐力永久消失**（hook 跨脚本生效，重载脚本也救不回来）；数值槽改写同样留着 |
| `SYS.SyncAntiRevert()` | `ClientReplicateCFrame.FireServer` 仍是被替换过的函数 —— 最典型的**可检测指纹** |

**修法**：在 `UnloadAll` 的"融合模块统一卸载"之后补这两个统一入口。
它们各自会看开关状态走"卸"那一路（本函数开头已把 `SYS.T_` 全置 false，所以必定走卸）。
> 顺带核实：`RayHook` 的 `__namecall` + 函数层 hook **已在** `SYS.FuseClean` 里还原 ✓。

### ②-3 ⛔ 静默失败面：`SYS.P` 是裸 `pcall`

```lua
local function P_(f,...) ... return pcall(f,...) end   -- 错误全吞
```

全脚本 **336 处 `pcall`**、处处用 `P(...)` 当"安全调用" ⇒ **任何运行时错误都不可见**，
表现是「这个功能没反应」而不是报错 —— 本项目最难查的一类 bug。

**修法**：升级为**错误台账**（限流设计，不会刷屏/掉帧）：
- 同一条消息**只打第一次**；最多记 **60 条**不同消息（超出归 `_other`）；最多打印 **30 条**
- 设置页新增 **🩺 内部错误台账**：查看全部 / 清空
- 📌 台账**空着**才是好消息

## ⑧ 词法级「写法 / 符号 / 语法」体检（2026-09-22 12:45，用户专项要求）

> `luau-compile` 只说"这一行有语法错"，**不说是哪一类**；而很多真会坏事的写法它**根本不报**。
> 新增 `_audit_syntax.py`（**已挂门禁 3.5/7**）补这一段。

### 方法：**双视图**（第一版栽在这 —— 值得记住的教训）

| 视图 | 构造 | 用途 |
|---|---|---|
| `mask` 代码视图 | 短字符串→`STR`、长括号串→`STR`、注释整段删除 | **所有语法级判据** |
| `text` 文本视图 | 只删注释、**保留字符串内容** | 只查"中文/全角符号是否落到**代码位置**" |

> ⛔ 只做一个视图 ⇒ 把**字符串里的中文**当成代码 ⇒ 一次报出 **164 个"全角句号"、213 行"裸反斜杠"**……
> **第一版报了 8 类"问题"，逐条核完真问题 0 个。**
> ⇒ **凡"一次报出几十上百条"的检查，先怀疑检查本身。**

### 查的 14 类（都能"编译过但功能不跑 / 卡死"）

1 字符串/注释未闭合（中文串里混 ASCII 双引号 —— 本项目连踩三次）
2 **中文出现在代码位置**（字符串被截断的唯一征兆）
3 全角标点落在代码位置 4 不可见字符（零宽空格/BOM/NBSP/全角空格）在代码位置
5 换行符不一致 6 代码位置的**裸反斜杠**
7 ★ **同一模块键定义两次**（`function SYS.X` 写两遍 ⇒ 后者静默覆盖前者，**前一个功能直接消失**）
8 `return` 之后的同块语句（不可达 ⇒ 功能主体没跑）9 `not a == b`（解析成 `(not a) == b`，判据反向）
10 长括号/块注释未闭合 11 可疑数字字面量
12 ★ **链式比较 `a < b < c`**（解析成 `(a<b)<c` ⇒ 运行时错）
13 字符串与算术运算符混用（`"n=" + x`，应写 `..`）
14 ★ **`while true do` 既无让出、也无 `break`**（真卡死客户端）

### 五类**必然假报**（判据已防住，每条都真踩过）

| 假报 | 真相 | 判据 |
|---|---|---|
| `return` 后"还有语句" | 多行 return：`return {`、`return a,`、`return (s:gsub(PAT, function(d)`、`return ("…")` 换行接 `:format(…)` | 前一行**括号不平衡**，或行尾是 `, { ( [ .. +/-*/ = and or`，或下一行以 `, ) } ] .. : or and` 开头 ⇒ 续行 |
| `while true` "卡死" | 循环体里**有 `break`**（扫字符串字节 / 扫 upvalue 下标），边界由条件保证 | 要求**既无让出也无 break** 才报（实测 3 处全部安全） |
| 中文标点"在代码里" | 在字符串里 | 只在 `mask` 视图查 |
| 反斜杠"在代码里" | `\n`、`%s+` 在字符串里 | 只在 `mask` 视图查 |
| 文件末尾"注释未闭合" | 最后一行是行注释 | 行注释在**换行处**结束（`\n` 时 `lc` → `code`） |

### 结论：**词法层干净，没有会导致功能跑不起来的写法/符号/语法问题**

```
✅ 字符串/注释全闭合（短字符串 · 长括号 · 块注释）
✅ 中文只出现在字符串与注释里 —— 代码位置无中文（说明没有"字符串被提前截断"）
✅ 代码位置无全角标点 · 无不可见字符（全角空格只在注释里, 无害）
✅ 换行一致：LF 18240 / CRLF 0 / 孤立 CR 0      ✅ 反斜杠只出现在字符串里
✅ 无重复模块键（不存在"后者覆盖前者"）          ✅ 无不可达 return
✅ 无 `not a == b` · 无链式比较 · 无字符串算术
✅ 3 处 `while true do` 全部有 break（有界循环, 安全）
ⓘ 1 处超长行：L17878（1295 字符）—— 提示, 不算错
```
