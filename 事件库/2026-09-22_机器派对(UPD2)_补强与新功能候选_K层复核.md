## 🔧 二、补强清单

### ① ★★ P0：K 值对象层在这台**完全失效** —— 134 个命中里 **130 个是动画噪声**

**实锤**（本次新抓的数据）：

| 命中来源 | 个数 |
|---|---|
| `Workspace.skins.Rig*.Animate.point` | **65** |
| `Workspace.skins.Rig*.Animate.wave` | **65** |
| `ANIM TEST.PlayerTest *.AnimSaves` | 8 行 |
| **合计** | **≈130 / 134（97%）** |

**根因两条**：
1. 状态关键词表里有 `point` / `wave` 这种**通用词** —— 而每个**皮肤骨架**都带一对同名动画辅助值（`skins.Rig1` … `Rig26`）；
2. 匹配是**子串**而非**整词**，更容易误撞。

**后果**：真正有用的状态值（阶段/计时/分数/目标）被这 130 条噪声**挤出"控制台前 40 条"** ——
用户看到一片 `Animate.point =`，**这层等于白加**。

**修法（三条一起）**：
- `point` / `wave` 从状态关键词表**移除**；
- **路径排除**：`Animate` / `AnimSaves` / `skins.Rig` / `ANIM TEST` 命中的一律跳过；
- 关键词改**整词匹配**（`%f[%A]词%f[%A]` 或按 token 比较），不再子串。

### ② P0：`SYS.Gun` 的 GC 扫描预算 —— 这台 31873 个函数

比 FFA 那台（13 万）轻，但**仍是上次定 4 万上限时的 1.5 倍**，
而扫描要读**每个函数的 upvalue 名**（`upNames` 最多 24 次/函数）⇒ **6 秒预算仍有截断风险**。

**统一修法（两台共用）**：用 B 层已验证的**「归属脚本」**能力把范围收窄到武器/命中/瞄准/弹药相关脚本。
这台 B 层同样给出归属 —— `AimHead`→`SpiderRig`、`Claim`→`PadBuy`、`Fire`→`Net`（`Fire` 还有两个归属 `-`，即匿名/引擎侧，本就不该动）。

### ③ P1：「对账 0/36」与「命中关键词 191 个」**在同一份报告里自相矛盾**

**实锤**：
- L399 `→ 命中可做功能的关键词 191 个 / Remote 总数 182`
- L1523 `── 功能类别通道对账: 有 0 / 共 36(其余 36 个本游戏没有同名通道) ──`

读起来像"这游戏什么都没有"，**实际是架构不同**：所有操作挤 `ReplicatedStorage.MachineParty.Event`
一条通道、靠**参数**区分功能 ⇒ 按名字匹配永远命中不了。

**修法**：
- 0/36 的措辞改成「**本游戏没有与菜单同名的通道（单通道架构）→ 不代表没有功能可用**」；
- 把**191 个关键词命中**列出来（现在只给了计数，用户看不到是哪些）；
- 单列一节「**本游戏自己的通道**」（含 `MachineParty.Event` / `UnreliableEvent` / `MP_Customization.Remotes.*` / `duck hunt.Sniper.Shoot`）。

### ④ P1：ClickDetector **逐身体部位**计数 ⇒ 同一个目标会被处理 20 遍

**实锤**：
- `Workspace.Lobby.MPStation_LimitedDrop.MannequinYou.<每个身体部位>.MPBuy_LimitedDrop`
  —— 一个"限时掉落商店"人偶 = **20+ 个 ClickDetector**（Head / LeftFoot / LeftHand / LowerTorso …）
- `MPStation_Event` = 5 个（Board / Body / Glow / Metal / Plinth）

**后果**：物件透视会把同一个商店**高亮 20 次**（视觉上糊成一团）；
自动交互类功能会**对同一目标重复处理**（既难看又在时序上是特征）。

**修法**：按「**去重键 = ClickDetector.Name + 最近的有意义祖先**（跳过身体部位/装饰件名）」合并，
**一个目标只算一次**。身体部位名表可直接复用：Head/Torso/Left*/Right*/HumanoidRootPart/Handle 等。

### ⑤ P2：`IntegrityCheckProcessor*` 被标「审计/日志通道」

这台被判高风险的**正好 2 条**，都是
`RobloxReplicatedStorage.IntegrityCheckProcessorKey2_*` —— 那是 **Roblox 自带的本地化遥测**，
**与游戏无关**（FFA 那台同样问题）。建议单独标注为「Roblox 自带」或直接排除，
免得用户把它当成"这游戏装了反作弊"。

### ⑥ P2：B 层「按归属脚本分组」只显示**字母序前 25**

这台前 25 里只有 `BumperMadness` / `BumperMadnessUI` 两个小游戏模块，
其余（`SpiderRig`、`RightOfWay`、`CrushHour`、`Blindout`…）**全看不到** —— 同 FFA 那台的问题。
修法：分组按「**与菜单功能相关的优先度**」排（小游戏 / 战斗 / 网络 / 交互 优先），不按字母序。

### ⑦ P2：本机没有 `getconnections` ⇒ J 层「谁在收」整列失效

每条都打一遍 `(无 getconnections)`（扫描已如实标注 ✅）。建议合并成**一行说明**，
免得用户误读成"没有人监听"。
