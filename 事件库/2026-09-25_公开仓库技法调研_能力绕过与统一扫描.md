## 二、逐能力：别人怎么做

### 1. 飞行 / 加速
- **Speed**：直接写 `humanoid.WalkSpeed`（最省事，也最容易被游戏每帧改写）。
- **Fly**：`BodyVelocity` + `BodyGyro` 挂 `HumanoidRootPart`，`MaxForce`/`MaxTorque = math.huge`，
  `humanoid.PlatformStand = true`，`RenderStepped` 里按相机向量算 `Velocity`；**不写 CFrame**。
- ★ **唯一值得借鉴的一点**：他们给自建实例起**随机名**（`_BV_NAME` / `_BG_NAME`）。
  ⇒ 我们 12.1.0 的**扫描里已经把这条登记成"可借鉴项"**：
  我们的「中性命名 / 擦掉 GUI 可疑名」只覆盖了 GUI，**角色身上的驱动实例名同样是检测面**。
- ⛔ 不抄 `SetNetworkOwner` 抢网络所有权 —— **Server Authority 已于 2026-07-09 正式发布**，
  SA 下网络所有权永远是服务端，`SetNetworkOwner` 直接报错。

### 2. 回血 / 锁血 / 上帝模式 —— 别人**根本没做**
- 两个 hub（DarkHUB / SpongeHUB）里**完全没有** godmode / 无限血 / 血锁实现。
- 这不是巧合，而是**物理事实**：血量与伤害在服务端结算，客户端做不了。
  ⇒ 与我们的结论**完全一致**：`补血 ✅ · 锁血 ⚠️（本地顶回，血条可能回弹）· 真无敌 ⛔`。
- 他们唯一的"替代品"：用执行器 `getconnections` 把**游戏自己挂的**
  `Humanoid:GetPropertyChangedSignal("WalkSpeed"/"MaxHealth")` 监听**掐掉**。
  ⚠ 本机执行器（Real）**没有 `getconnections`** ⇒ 这条路我们走不了（别看了浪费）。
- 另一条已证伪的老路：直接 `FireServer` 资源模板远程赌"服务端不校验持有"
  —— 我们 11.8.2 试过、11.8.3 实测无效已删。**别回加。**

### 3. 高亮 / 透视
- 主流做法：`Drawing.new("Square"/"Text"/"Line")`。★ 关键点：**`Drawing` 对象不是 `Instance`**，
  所以反作弊遍历 `PlayerGui` / `GetDescendants` **抓不到**。
  代价：没有 Roblox 的光照/遮挡/交互表现，不跟 UI 缩放，纯屏幕坐标绘制。
- 我们走 `Instance` 高亮（`Highlight`）是**有意的取舍** ——
  用户实测定案「**位置正确 > 反检测收益**」，且名字能中性化、能统一管理。
  ⇒ 这条取舍我们不翻，但把它**登记进扫描**，让用户知道代价是什么。

### 4. 传送 / 移动
- 外部基本是"直接写 CFrame / 单帧大跳"，没有分步。
- 我们的 `SYS.TPTo` 走**分步链**（多帧小步）+ `C_.RevertJump` 自适应阈值 —— 这条路比他们稳。

## 三、★ 反作弊对抗：别人的四招，以及我们为什么大量不抄

| 别人的招 | 具体做法 | 我们的裁决 |
|---|---|---|
| **`__namecall` 总入口 hook** | `hookmetamethod(game,"__namecall")` 拦 `Kick`/`KickPlayer`/`Ban`/`Report`/`FireServer` | ⛔ **绝对不做** —— AGENTS §1 第 3 条：那是所有实例方法调用的总入口，**实测就是卡顿掉帧的病根** |
| **扫全树摧毁 AC** | 按名字匹配 AC/Kick/Ban，对 `RemoteEvent`/`LocalScript` 直接 `Disabled=true` + `Destroy()`；再挂 `game.DescendantAdded` 监控后续补进来的 | ⛔ 不抄（见 §四：对**动态注入式** AC 是自杀） |
| **指纹擦除** | 删 `getgenv()` 里的执行器全局 · 把 `identifyexecutor` 伪造成 `"Roblox"` · hook `loadstring` 过滤 AC 源码 · hook `require` 拦 AC 模块 · 改环境元表 `__index` 让索引返回 nil | ⛔ 不抄：删执行器全局 = 自己也没得用；改元表 = 红线 |
| **伪装"活着"** | 每 30~90 秒给 `LocalPlayer` 写一个 `Heartbeat` Attribute | ⚠ 存疑，**未采用**：服务端若不认这个属性，写它反而是**额外特征** |

另外看到一个**反面教材**：某 hub 的 `SpoofName` 配置项存在、UI 能点，**代码是 no-op**（把原函数透传一遍）。
⇒ 这正是本项目 V3 把「**错误显形**」做成本能的原因：**静默的假功能比没功能更坏**。

## 四、★★ 本次调研最重要的一条：反作弊分两类，先判类型再决定做什么

从 `CISI-ACF`（动态注入式反作弊框架）学到的东西**比所有外挂仓库加起来都多**：

### A 类 · 静态扫描式
遍历 `PlayerGui` 读 `.Text` / 找特征实例名 / 比较函数身份 / 查执行器全局。
⇒ **④ 检测面层有用**：中性名 + 关闭时文字脱敏 + 少留特征实例。

### B 类 · 动态注入式（CISI 模型）
- 服务端**随机间隔**（带随机噪声）往客户端注入 inspector 脚本；
- inspector 算一个值 → `FireServer(code)` 回报 → 服务端用 `DependantValues` 重算比对；
- **ReportTime 到点没回报 ⇒ 判定"反作弊被动过"**；
- 配置按**玩家分组 / 会话分组**发，绕过方法**无法在社区扩散**。

⇒ **对 B 类的三句结论（直接改写了我们的绕过策略）**：

1. **拦通道 / 删 remote / 断网 = 直接吃超时判罚。** 它要的就是"你没回话"这件事本身。
   ⇒ 我们的 `ACBlock`（拦截名字像 AC/审计的上行）**遇到 B 类反而是负收益**，要谨慎开。
2. **改名 / 清执行器全局 / 擦指纹 = 完全无效。** 它压根不看这些。
3. **唯一活路是"让上报的数值自洽"** —— 也就是：**别伪造，只做本地表现**。
   这恰好就是我们项目一直以来的立场（不做服务端伪造），**外部调研反过来证明了它是对的**。

⇒ **怎么判自己是哪一类**：看新的「🛡 能力绕过判定」+「反作弊模块痕迹」两节；
出现「**随机间隔 + 限时回报 + 数值比对 + DependantValues**」特征 = B 类。

## 五、落地：「全部放在一个扫描功能里面」

**12.1.0 之前**：项目里已经有统一扫描器（`SYS.Scanners` + `SYS.RegisterScanner` + `SYS.ScanAll`，
UI 上就一个「🔍 综合扫描」按钮，12 层一次扫完），但缺三块：
① 六个能力的**能不能做 / 怎么绕**；② V3 的**事件图谱与监听面**；③ 散在 4 个按钮里的自检。

**12.1.0**：把 4 块全部**注册成 Scanner** ⇒ 一次「🔍 综合扫描」全覆盖，**不新增第二个扫描按钮**。

| # | 新 Scanner | 内容 |
|---|---|---|
| 1 | **🛡 能力绕过判定** | 飞行加速 / 回血 / 锁血·防击倒 / 上帝 / 高亮透视 / 传送 / 反检测 —— 逐条给「判定 + 打哪一层 + 怎么做 + 做不到什么 + 别做什么」；开头先给三条硬前提（`AuthorityMode` / 网络所有权 / `StreamingEnabled`） |
| 2 | **🧩 事件扫描** | V3 事件图谱按 7 类计数 · 已挂/挂起监听 · 5 个新增监听面状态 · 任务/驱动连接/错误数/每帧负载 · 最贵 5 个任务 · 错误显形清单 · 最近 8 条下行事件 |
| 3 | **🧪 自检合集** | 移动自检 + 高亮彻底性 + 穿墙/射线改写统计 + 武器数值槽（原来散在 4 个按钮） |
| 4 | **🕵 外部手法对照** | 本文 §二~§四 的结论，直接进扫描输出（别人怎么写 / 我们为什么抄或不抄 / A类B类判定法） |

**扫描器总数：15 → 19**。另加一个直通按钮「🛡 能力绕过判定」（只打印第 1 块），
并在「综合扫描」的说明里写清新并入的 4 块 —— 用户点一个按钮就够了。

### 关键实现细节
- 新 Scanner 插在 `SYS.ScanAll()` **之前注册** ⇒ 在报告里**排最前**，点一下先看到能力判定。
- 全部走**只读**：读 `AuthorityMode` / `GetNetworkOwner()` / `SYS.FindEvent` / V3 的图谱与计数，
  **不发任何上行、不改任何属性**。
- 扫描里显式写清「**做不到**」的部分（凭空回血 / 真无敌 / SA 服移动 / StreamingEnabled 的远处透视）——
  扫描的价值有一半是**告诉你哪条路别走**。
