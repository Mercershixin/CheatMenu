## 三、发现 1（真问题）：`check.py` 有**过期断言** → 假阳性

- 失败项原文：`玩家透视又偏移颜色/淡化: 或隔墙不区分, 或退回金色`
- **规则**断言字面量：`fillT=wall and 0.93 or 0.88`
- **实际源码**（`espFill`，L5121 起）：早已按 **v10.7.0「隔墙高亮形态」** 改成
  `h.FillTransparency = wall and 0.93 or 0.88` **＋** `HL_SOLID=0.35 / HL_LINE=0.93` 两形态，
  颜色仍 `Color3.fromRGB(0,255,90)`（队友绿）/ `(255,40,50)`（敌人红）；6 处高亮全部走 `espFill(h,wall)`。
- **判定**：**代码是对的，门禁是旧的** —— 断言还停在 v10.7.0 之前的变量名 `fillT`。
- **处置（已做）**：把 `check.py` 断言改成**当前实现**（`function espFill(h, wall)` + `HL_SOLID = 0.35` + `HL_LINE` + 两个颜色）
  ⇒ `check.py` 复跑 **问题数 0 ✅**。⚠ 这是**纯工具链改动，不占版本号**（源码一个字没动）。

## 四、发现 2：4 个「死键」（**只报不删**）

`FullBright` · `NightVision` · `NightVisionPro` · `SuperLight`

- 现象：**有读无写**（`ReapplyLight` 里读，L13408–13420），但**没有任何 UI 控件能置位**。
- 但**不是完全死**：`L515` 是 `if type(v)=="boolean" then data.T_[k]=v end` ——
  **存档里的布尔值会写回 `T_`** ⇒ 老配置文件若把它们存成 `true`，`ReapplyLight` 仍会生效。
- 定性：**光照模块的历史项**（现由 `LightMode` 下拉 + `NoFog`/`NoShadow`/`Lantern` 取代）。
- **处置：不动。** 理由：① 项目规矩「无 UI 入口 ≠ 回归」，要判回归得看 CHANGELOG 有没有记这次删除
  （历史「界面已删、后端保留」见 CHANGELOG 6.9.11，当时明确写了「这批我先没动」）；
  ② 删它们属于**功能清理**，得你点头。**建议**：要清爽就下一轮专门做一次「遗留键清理」，一次删干净并进 `REMOVED_FEATURES`。

## 五、发现 3：`SYS.CurKick` 零引用（**不删**）

- `_audit_deadcode` 判为 A 档「可安全删」：全文件零引用、名字不在任何字符串里。
- **但源码 L8091–8092 紧邻写着**：
  > `-- ⛔⛔ v10.3.0 删除: SYS.CurReb()...`
  > `--   ★ 保留 SYS.CurKick / AFK.Kick / KickData 监听: 那是通用「当前 Kick 数值」读取器, 与重生无关。`
- **判定**：**故意保留**（通用读取器，供以后功能复用），**不是漏洞**。
- ⚠ 顺带记录审计脚本的一个**小盲点**：它的「B 档 = 有『别删/预留』标注」只认**定义处附近**的标注，
  而这条「保留」写在**紧随其后的一行注释**里、只点名不紧贴 ⇒ 被误归进 A 档。**建议**把 B 档判据放宽为
  「定义处 ±5 行内出现该函数名 + 保留类词」。**本报告只记录，未改脚本**（避免动到别人的判据）。

## 六、非问题（解释清楚，别当 bug）

1. **`luau-analyze` 1394 条 `TypeError`**：全部是 `Unknown global 'game' / 'task' / 'warn' / 'Enum'` 与
   「Code is too complex to typecheck」—— **因为没加载 Roblox 类型定义**（`roblox.d.luau`）。
   对纯 Roblox 脚本这是**预期噪音**，不代表代码有错。⇒ **结论仍以 `luau-compile` + `check_globals` 为准。**
2. **`_audit_ui_binding.py` 直接跑会 traceback**（找不到 `C:\Users\Administrator\Desktop\1.txt`）：
   **设计如此** —— 它头部写明只认**第三方源脚本**那套 `Create*({...})` / `CurrentValue=Config.X` 写法，
   查 CheatMenu 要用 `_audit_switch_wiring.py`。**不是坏工具，是用错工具。**
3. **`timeout` 命令报「默认选项不允许超过 '1' 次」**：本机 `timeout` 落到 **Windows `timeout.exe`**，
   不是 GNU 版。⇒ 脚本别前缀 `timeout`。（与「本机 GNU coreutils 残缺」同一类坑，`sort`/`uniq`/`grep` 亦然。）
