# 2026-09-24 · 全功能复查（11.4.1）—— 还有哪些 bug / 漏洞

> 起因：用户「继续检查全部功能 还有没有bug 漏洞」。
> 范围：① 11.4.0/11.4.1 新增代码（风险最高）；② 新代码与既有模块的交互点；③ 开关接线四点；④ 卸载/还原对称性。
> 手段：静态阅读 + 符号计数核实（**没有跑仿真，没有跑整脚本**）。

---

## 一、✅ 确认为真 → 已修（5 项）

### 1. 🔴 `SYS._fireLog` 只读不写 ⇒ D11「上行速率指纹」是死代码
- **证据**：`grep _fireLog` 全仓只有 2 处 —— `SYS._fireLog={}`（18642）与 `local t=SYS._fireLog`（18644）。
  **`SYS.Fire` 里根本没有追加过时间戳**。
- **表现**：`SYS.AC` 的 D11 永远报「近 10 秒上行 0 次」，H.8 心跳频率指纹同样永远为空；
  「间隔标准差 < 5ms 报警」这条永远不会触发 —— 看着像在工作，其实是死的。
- **修**：`SYS.Fire` 里真正记录时间戳，并**环形裁剪到最近 400 条**（防无限增长）。
- **默认行为**：不变（D11 从"永远 0"变成真实数字）。

### 2. 🟠 H.3「参数类型不符 ⇒ 拒绝发送」会**静默丢掉合法上行**
- **证据**：`SYS.Fire` 里同一 remote 连续 3 次同类型签名后，只要类型变了就 `return false`（940 行附近）。
- **风险**：这是**静默失败**——调用方拿到 `false` 但没人提示（只有一条 Notify），
  典型后果就是"某个功能突然不工作了、还不知道为什么"。**和这次 11.4.0 踩的坑是同一类。**
  现实里很多游戏同一个 remote 会合法地传不同参数（可选参数、`nil`、先 Instance 后 string）。
- **修**：改为**只警告、不拦**（`SYS._FireTypeWarn` 计数 + Notify + 进自检）。
  ⚠ **这是对 11.4.0 单子 H.3 字面要求的偏离**（单子写「拒绝发送」）—— 理由是"静默丢上行"风险 > 收益；**用户可否决**。
- **默认行为**：该守卫从「会拦」变成「只报」，**上行不再被丢**。

### 3. 🟠 卸载顺序 ⇒ **ACBlock 的 wrapper 被重新装回去（hook 残留）**
- **链**：`UnloadAll` 里顺序是 `SetAntiCheatBlock(false)` → … → `UnhookAllSafe()` → … → `SYS.SyncAntiRevert()`。
  `AR.Off()` 会执行 `hookfunction(AR.ev.FireServer, AR.orig)` —— 而 `AR.orig` 在 ACBlock 之后挂钩时
  **正是 ACBlock 的 wrapper** ⇒ 卸载末尾把它**又装了回来**，真正的原函数被顶掉。
- **表现**：本身不崩（`ACB.on=false` 会直通），但**留了一个可被 `debug.info` 看穿的 hook 残留**，
  与「关掉必须真正还原」的项目铁律冲突。
- **修**：`AR.Off` 在 `SYS.Unloaded` 为真时**跳过还原**（交给 `UnhookAllSafe`/`restorefunction` 收尾）。
- **默认行为**：不变（只影响卸载路径）。

### 4. 🟡 卸载时会弹 **4 条虚假「已关」提示**
- **证据**：`🧬 Attribute 回写已关`(18450) / `🎥 相机护栏已关`(18464) / `📍 位置下行回压已关`(18505) /
  `📡 firesignal 伪装已关`(18546) —— **off 分支无条件 Notify**，而 `UnloadAll` 无条件调用它们。
- **表现**：只要卸载（关脚本/热更新），不管这几个开关**原本开没开**，都会弹 4 条"已关"。
- **修**：4 处加「原来开着才提示」。
- **默认行为**：不变（少 4 条假提示）。

### 5. 🟡 `SYS.Stagger` 是死代码 + 只读监听可能接入过量通道
- **证据**：`grep Stagger` 只有定义（18743），**没有任何调用点** ⇒ L.3 实际等于"只留了个空壳"。
- **附带风险**：`SYS.StartACWatch` 会把**所有**命中 `EventWatch.keywords` 且 `RemoteRisk` 为**真值**的 RE/URE
  全接上 `OnClientEvent` —— 而 `RemoteRisk` 对「ℹ Roblox 官方自带」那类**也返回真值**
  ⇒ 会接上一堆与反作弊无关的官方/正常通道（连接数与控制台输出都变多）。
- **修**：① `StartACWatch` 只接 `RemoteRisk` 判为 **⛔/⚠** 的（与 `ACBlock` 口径一致）；
  ② 连接数上限 **60**；③ 每 8 条插一次 `RS.Heartbeat:Wait()`（这才真正落地 L.3 的"实例/连接错峰"）。
- **默认行为**：变（少接无关通道）。**这是修 bug，不是加功能。**

## 二、⏭ 记录但**未改**（需要用户点头 / 属设计取舍）

| 项 | 说明 | 为何没动 |
|---|---|---|
| **Attribute `State="Alive"` 是猜的** | `AttrGuard` 写回时把 `State` 从 `Dead` 改成 `"Alive"` —— 这是我们假设的取值。若游戏用的是别的枚举（如 `0/1`），写进去反而是垃圾值 | `AttrGuard` **默认关**，且属"填什么值"的策略问题；想改先要某个真实游戏的 Attribute 结构 |
| **`ACBlock` 候选名会过期** | `ACB.names` 是开机时扫一次；换图/游戏动态创建 remote 后**不会重建** ⇒ 新出现的通道不拦、旧的不再存在也不报错 | 修复需要地图变化监听（`Workspace`/`RStorage.ChildAdded`），算**新增行为**；建议用户需要时手动重开开关 |
| **`ACBlock` 默认开** | 单子 §13 定的默认开。实测风险是"可能拦到游戏自己的通道"（已收窄到 ⛔/⚠ 判定） | 改默认值属**行为变更**，等用户表态 |
| **`SYS.Fire` 抖动用 `task.wait`（会 yield）** | 非协程上下文里会静默降到"不抖动" | 已用 `pcall` 包住保证"至少发得出去"；要彻底解决得换 `task.delay`，属重构 |
| **`StartAdminWatch` 的 `PlayerRemoving` 会打印每个玩家离开** | 有 200 条环形 + Notify 限 3 次/标签，但 `print` 每条都打 | 单子 F.3 明确要求"也记一条"，属规格内行为 |

## 三、✅ 复查通过（无问题，列出来是为了"确实查过"）

- **开关接线四点**：`ACBlock`/`AntiRevertExtra`/`AttrGuard`/`CamGuard`/`PosRebound`/`CB_BlockDeathSignal`/
  `StealthReg`/`FireSignalSpoof` 八个新开关 —— `T_` 默认值 ✅ · 模块本体 ✅ · `UI.Switch` ✅ · 卸载清单 ✅（纯标志位 3 个无需清理）。
- **`C_` 新键**：`FireJitter` / `CamGuardDist` / `MoveSmooth` / `JumpSpoofMode` / `FireTypeSigN` / `FlyAbs` / `SpeedAbs`
  —— 都在 `C_` 表内，`SaveConfig`/`LoadConfig` 能存能读（`LoadConfig` 要求键已存在，故必须进默认表 —— 已进）。
- **卸载对称性**：所有 `hookfunction` 点（`ACBlock` 走 `SafeHook`、`AntiRevert` 走裸 `hookfunction`、
  `Stealth` 各层走 `ST.Extra`+`SafeUnhook`、`firesignal` 走 `SafeUnhook`）都有还原路径（`AR` 的问题见 §1.3）。
- **`Lua` 中文字符串引号红线**：`luau-compile` exit 0 ⇒ 新增的 Tip/Switch 文案里没有 ASCII `"` 截断字符串。
- **`SYS.SmoothSpd`**：首帧/长间隔（>0.4s）直接返回目标值，之后按 `MoveSmooth` 收敛 —— 不会出现"永远 0"。
- **`SpeedTick`/`FlyTick` 互斥**：`SpeedTick` 开头 `if not T_.Speed or T_.Fly or FreeCamActive then return` ⇒
  两者不会同时调 `SmoothSpd`，共享状态 `SYS._smCur` 无竞争。
- **`AntiFling` / `AntiRevert` 阈值**：11.4.1 已改为随目标速度自适应，不再有写死的 80 / `16×3`。
- **`ACBlock` 的「ℹ Roblox 官方自带」判定**：11.4.1 已排除（只拦 ⛔/⚠）。
