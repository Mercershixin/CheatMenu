关于两套数字的差额（别被绕进去）： 页面上一共 65 个开关控件，而 SYS.T_ 声明表里有 105 个键。差额来自三处： ① 被其它控件联动的子开关（例如「🔍 物件透视」一个总闸去同步 ESPItem / ESP_Door）； ② 合并后留下的旧键（残键，如 CB_Silent / CB_SnapFire，仍被主循环读，见 AGENTS.md §2-B）； ③ 内部标志。声明表键数还含少量解析噪声（false / true / X / Z）。
