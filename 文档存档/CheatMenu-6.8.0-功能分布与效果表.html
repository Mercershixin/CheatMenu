2) 本版补强（已有功能的行为变化）

功能改动前改动后你要注意什么
🛡 上帝模式只做「血量掉下去立刻补回 + 断关节保护」 自动带上「防死亡 + 防击倒」：血量 ≤0 立刻恢复满血，倒地 / 摔趴状态自动站起 与「反陷阱免伤」同开时仍会互相让位（既有逻辑）；服务端结算的致命伤仍可能生效
🎯 自动瞄准每帧无条件下转相机 受「命中率 / 漏打」两个闸门控制；两闸门默认全放行 → 不开新控件时与 6.6.0 手感完全一致 想要原手感就别动这两项
🎯 选人（isEnemy）只有队伍 / 无敌盾 / 存活判据 最前面加一道白 / 黑名单闸门；两个名单都为空时直接放行 → 与 6.6.0 行为一致 白名单非空但目标不在场时会一个人都不打（预期）
⌨ Ctrl+数字 直达只索引「已保存位置」 若「Ctrl+数字 用于路径点」打开且该序号有路径点 → 优先去路径点，否则回退旧行为 默认关，不改变现有手感
🧹 卸载（UnloadAll）原有 30+ 项还原 追加 8 类还原：滤镜 / 光照 / 音频 / 聊天 / 路径点 / 防护 hook / 射线 hook / 玩家控制与整蛊循环 卸载后 hook 会真正卸下（射线 hook 关掉最后一个才卸）
📱 界面缩放上限被写死成 1（只缩不放）
v120 为修「菜单超出屏幕 → 右边按钮点不到」加的；但真正的元凶是旧下限 lo=0.75		 恢复放大能力，按设备给上限：纯触屏(手机/平板) 1.75 · 小视口 1.35 · PC 1.0。
仍是 sc = min(fit, 上限)，而 fit 已扣掉刘海/顶部栏边距 → 永远塞得进屏幕，不会重现「点不到」。
另外设置页可手动覆盖（0 = 自动）+ 一键恢复自动 + 设备诊断。		 手动拉得过大（超过 fit）菜单会超出屏幕 —— 那时拉回来或点「恢复自动适配」。
手机/平板上体感变化最明显：菜单整体放大最多 75%，字随之等比放大。
默认状态总结：本版所有新增开关一律默认关；6.6.0 就有的规矩不变 —— 开关状态不写进配置文件，每次加载都用代码默认值。
你点名要「加入但默认关闭」的三项 —— 静默瞄准 / 子弹穿墙 / 阻挡射线检测 —— 都在「战斗 → ⚠ 高风险瞄准」里，需要时手动打开。
你点名不要的 本地音乐播放器 / 动画播放器 已跳过。
「粘性瞄准（锁定保持）」没有加回：你早前明确要求删除过，check.py 里带回归锁（lock('CB_Sticky' not in nocmt, ...)）。 这次只加了「命中率 / 漏打」两项 —— 需要粘性瞄准请单独说一声，我把锁一起改掉再加。
