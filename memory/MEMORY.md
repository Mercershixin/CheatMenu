## 技术事实（删了会直接崩）

1. 元方法钩子里不能调会再次触发同一钩子的 API（重入⇒爆栈）；先判方法再干活。
2. 「关/复位」要还原到加载时记录的原值（`F.RecordOriginals()`）；没记录就一个字节都不写。
3. 删功能要扫全部调用方；删 `local` 声明必须连"使用"一起删（否则变隐式全局）；删后做传递闭包复扫（`deadfix.py`）。
4. ★★★ `local function` 写在调用点之后 ⇒ 那处引用是 **nil 全局**（编译期词法解析；`F.X = function()` 才运行时可后置）。
   症状 = `pcall(nil)` 静默失败 / "开关拨了没效果"。
5. ★★★ **热键"按了完全没反应"先查 `gameProcessedEvent`**（菜单 Modal 覆盖层 / 聊天框焦点 / 游戏绑键都会吃掉）
   ⇒ **F 键一律豁免 gp**。**取鼠标位置**：锁定态下指针根本不存在，必须"逐帧顶住解锁 + `ScreenGui`→`TextButton` 取点层"；
   坐标空间只许一套 `GetMouseLocation()`（`input.Position` / `SendMouseButtonEvent` 同一套），**不用 ±36 补偿**。
6. ★★ **`Disable()` 单向**：禁用了游戏的事件连接 ⇒ 效果停在当前帧；`Enable()` 不补跑 ⇒ 关闭时要人为造一次事件唤醒（`F.DmgFxThaw`）。
7. ★★ **"开关开了但功能不生效"先查状态副本**：是否一个概念被多处状态耦合、其中一处只在本次会话有效 ⇒ 判定只认一个开关；
   **只写不读的幽灵状态要连根删**；"读/写"共用同一口径。
8. ★★ **Roblox 属性名大小写敏感**：`GetAttribute("durability")` 读不到 `Durability` ⇒ 一律 `GetAttributes()` 拉全表、小写化比对，**回传真实属性名**。

- ★★ **出站改写只有一个 `__namecall` 钩子**（拦上报/位置伪造/游戏绕过共用一个）；档位 ②/③ 自动装、`_tierGbypOwn` 记所有权、
